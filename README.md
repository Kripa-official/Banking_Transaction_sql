# 💳 FinTech Transaction Risk Behavioral Analysis using SQL

## 📌 Overview

This project analyzes banking transaction data using SQL to identify fraud patterns, customer spending behavior, transaction trends, and risk indicators. It demonstrates SQL-based data analysis to generate meaningful business insights.

## 🛠️ Technologies Used

* SQL
* Microsoft SQL Server
* Visual Studio Code (VS Code)
* Git & GitHub

## 📊 SQL Concepts Used

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* Aggregate Functions (`COUNT`, `SUM`, `AVG`, `MAX`, `MIN`)
* CASE Statements
* Date Functions

## 📈 Key Analysis

* Total & fraudulent transactions
* Fraud percentage
* Customer spending analysis
* Merchant category analysis
* Payment method & device analysis
* Risk level analysis
* Monthly transaction trends
* Dashboard summary

## 🎯 Outcome

This project showcases practical SQL skills for analyzing financial transaction data, detecting fraud patterns, and generating business insights.
